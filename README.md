## Winnipeg interior wall concepts (1530 Dakota St)
`winnipeg/interior/`: before/after mockups on the real site photos, plus the flat artwork (`art-*.png`) for the printer.
- **Long wall** (`long`): newspaper collage with sauce stickers, oak wainscot on the bottom third, flavour board in a black frame, a red "Ask for the flavour of the week" plaque, SK/MB/JP plates and crossed rackets.
- **Black window panels** (`panels`): 3 menu screens (Wings, Burgers, Platters), and a "Deal every day" chalkboard below them.
- **Kitchen door wall** (`door`): newspaper collage plus a SAUCE LAB neon sign.
- **Farm wall** (`farm`): black line-art prairie mural (barn, WING-O grain elevator, windmill, wheat) with SK and MB plates.

## Winnipeg sauce board (6 ft x 4 ft)
`winnipeg/sauce-board/`: all 131 flavours in 8 categories (incl. The Garlic Vault) with the Sauce Boss signature, with heat/taste dots and a chili icon on hot flavours.
- `wingo-winnipeg-sauce-board-6x4ft.pdf`: send this to the printer. Sharp vector text, exactly 72 x 48 in.
- `wingo-winnipeg-sauce-board-6x4ft-150dpi.png`: the same board as a 10800 x 7200 image, for printers that want an image file.
- `wingo-winnipeg-sauce-board-preview.jpg`: small preview for phones.
- `wingo-winnipeg-sauce-board-menu-style-*`: the same board in the style of the in-store menu (grey chalk background, red serif headings, Josefin Sans, sketch art from the menu).
